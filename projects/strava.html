Strava

Hello, LA.

LA’s street grid is a pixel font. Seven run clubs each run one letter, and together they spell HELLO LA across Koreatown. Every letter is a real route on real streets, drawn in code from OpenStreetMap data, that anyone can save and run.

Creative direction · Social campaign · Data-driven design · Copy · Motion
01 / The briefInsight, idea, direction.

Strava art is
already a scene.
Why this idea, for this brand.

The launch

Strava has more than 200 million users (Oct 2026). Clubs on Strava passed one million in 2025, and running clubs grew 3.5×. Strava already celebrates GPS route art with an official Strava Art Club, and its route search now works “in your own words” (Oct 22, 2026).

The insight

Run clubs are LA’s new social life, and GPS art is something runners already do for fun. Nobody has turned it into a city-scale group project.

The idea

Hello, LA. Give each club one letter. The grid does the typography; the runners do the writing. The finished sentence only exists when everyone has run their part.

01

Real streets, real routes.

Every letter follows actual Koreatown streets, from Wilton Place to Westmoreland Avenue and 2nd to 12th Street, so the campaign is a set of routes people can run, not a picture of one.

02

The grid is the font.

Blocky letters suit the street grid. I tested neighbouring streets and kept the straightest ones so the letters stay legible on the map.

03

One club, one letter.

The participation mechanic is the media plan: seven clubs, seven posts, one shared reveal.

02 / The routesSeven letters, 13.5 km in total.

Save one.
Run it.

The carousel gives each letter its own slide, with distance and the streets it covers. Each route exports as a GPX file you can load into Strava or a watch. Some letters retrace a block, which is how GPS art works.

What it is not

An unsolicited spec concept, not commissioned or approved by Strava. The routes are real streets but have not been run or checked for safety. No run clubs are affiliated. Street data © OpenStreetMap contributors. No Strava logo or app UI is recreated.
